# text2txt

Highlight some text, right-click, hit **Save Selection as TXT…**, pick where it goes. That's it.

It doesn't read your browsing history, track you, or send anything anywhere. It only looks at the page you right-clicked in, at the moment you click, and only to grab the selection and the title.

## Install

1. Go to `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and pick this folder.
